# 크앙사주

아기호랑이 **크앙**이 어려운 사주 용어를 생활 언어로 풀어주는 모바일 웹앱 프로토타입입니다.

## 실행

정적 웹앱이라 `index.html`을 브라우저에서 열면 됩니다.

GitHub Pages 또는 Vercel에 배포할 때는 저장소 루트의 `index.html`과 `assets/` 폴더를 그대로 사용하세요.

## 현재 기준 버전

- v5 친구상담형
- 큰 글씨와 밝은 카드 UI
- 민화풍 배경 / 크앙 캐릭터 / 오행 및 소품 에셋
- 생활 밀착형 상담 카드
- 말투 선택: 몽글몽글 / 솔직하게 콕 / 돌직구 크앙
- 어려운 한자와 전문 용어는 상세 계산 영역에만 노출

## 계산 엔진

온라인에서는 `manseryeok 2.0.0` ESM을 먼저 불러오며, 연결 실패 시 내장 계산기로 전환합니다.
