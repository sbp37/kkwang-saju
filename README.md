# 크앙사주

아기호랑이 **크앙**이 어려운 사주 용어를 생활 언어로 풀어주는 모바일 웹앱 프로토타입입니다.

## 실행

정적 웹앱이라 `index.html`을 브라우저에서 열면 됩니다. 빌드 도구가 필요 없고, 인터넷 연결 없이도 같은 결과가 나옵니다.

GitHub Pages 또는 Vercel에 배포할 때는 저장소 루트를 그대로 올리면 됩니다.

## 파일 구성

```
index.html          화면 마크업 · 스타일 · 렌더링
engine/ssaju.js     만세력 (ssaju 0.2.0, MIT)
engine/ksaju.js     한국 시간 보정 + 신강신약·용신·격국 판정
rules/reading.js    내 사주 해석 규칙
rules/match.js      궁합 규칙
rules/today.js      오늘운세 규칙
assets/             배경 · 캐릭터 · 오행 이미지
```

모두 클래식 스크립트라 `file://`로 열어도 그대로 동작합니다. ES 모듈이나 `fetch`를 쓰지 않는 이유가 이것입니다.

### 문장을 추가하려면

풀이 문장은 코드가 아니라 `rules/` 아래의 규칙 배열에 들어 있습니다. 규칙 하나는 이렇게 생겼습니다.

```js
{
  id: '재성-시지',
  slot: '돈버는방식',                       // 어느 섹션에 넣을지
  when: c => c.궁위.시.branchGroup === '재성',  // 언제 이 말을 하는지
  weight: 74,                              // 여러 개가 맞으면 높은 순으로
  text: c => '돈 이야기가 초년보다 뒤에 커지는 자리야.'
}
```

배열에 하나 더 넣으면 끝이고, 조건에 맞는 사주에만 나옵니다. `fallback: true`를 달면 다른 규칙이 하나도 맞지 않았을 때만 쓰입니다.

## 현재 기준 버전

- v5 친구상담형
- 큰 글씨와 밝은 카드 UI
- 민화풍 배경 / 크앙 캐릭터 / 오행 및 소품 에셋
- 생활 밀착형 상담 카드
- 말투 선택: 몽글몽글 / 솔직하게 콕 / 돌직구 크앙
- 어려운 한자와 전문 용어는 상세 계산 영역에만 노출
- 궁합: 두 사람의 일간·일지·용신·격국을 맞대어 관계의 결을 읽습니다
- 오늘운세: 오늘 일진이 내 사주를 어떻게 건드리는지 + 이번 달 흐름
- 마이: 생년월일·말투를 이 기기에만 저장 (기본 꺼짐)

## 궁합

점수를 매기지 않습니다. 이 앱은 10년 흐름도 좋고 나쁨 대신 "어떤 주제가 반복되는지"로 보여주는데, 궁합도 같은 원칙으로 몇 점이 아니라 **어떤 결의 관계인지**를 설명합니다.

- **일간끼리** — 상대가 나에게 어떤 십신인지, 천간합·천간충이 있는지
- **일지끼리** — 배우자 자리끼리의 육합·삼합·충
- **용신 보완** — 내게 필요한 기운을 상대가 갖고 있는지, 그 반대인지
- **오행 합산·격국 조합·띠(연지) 관계**

결과는 처음에 끌리는 지점 / 같이 있을 때 편한 것 / 부딪히기 쉬운 지점 / 오래 가려면 네 갈래로 나오고, 무엇을 보고 그렇게 말했는지 근거를 함께 표시합니다.

## 해석 방식

사주 여덟 글자를 십신 그룹 개수로만 압축하지 않고, 아래 축을 함께 봅니다.

- **격국** 11종 — 월지가 일간에게 어떤 역할인지로 갈리는 유형
- **궁위** — 같은 십신이라도 연·월·일·시 어느 자리에 있는지에 따라 다르게 읽습니다
- **통근·투출** — 뿌리 없는 글자와 겉으로 드러난 글자를 구분합니다
- **12운성** — 각 자리의 기운이 오르는 상태인지 모으는 상태인지
- **12신살·특수신살 / 합충형파해 / 공망**
- **세운** — 올해 간지가 원국의 어느 자리를 충하거나 합하는지까지 봅니다

문장은 고정된 표를 조회하는 대신 조건부 규칙으로 조합합니다. 각 규칙은 "언제 이 말을 하는가"를 조건으로 갖고 있어, 사주에 맞는 규칙만 골라 점수순으로 조립합니다.

계산에 필요한 것이 모두 `index.html` 안에 들어 있어 인터넷 연결 없이도 같은 결과가 나옵니다.

- **팔자 계산**: [`ssaju`](https://github.com/golbin/ssaju) 0.2.0 (MIT) 내장 — 사주 팔자, 지장간, 십신, 12운성, 합충형파해, 신살, 공망, 대운을 계산합니다. 절기 절입 시각까지 반영합니다.
- **시간 보정**: 서울 경도(126.978°) 기준 진태양시, 균시차, 한국 서머타임(1948–51 / 1955–60 / 1987–88), 표준시 변경(1954–61 UTC+8:30)을 앱에서 직접 보정합니다.
- **판정**: 신강·신약, 용신, 격국은 지장간 일수 배분과 월령 가중치를 쓰는 자체 로직으로 판정합니다.

억부를 기본으로 보되 계절이 극단이면 조후를 우선합니다. 신강·신약과 용신은 유파에 따라 결론이 갈리는 주제이므로, 앱은 계산 근거를 화면에 함께 표시합니다.
